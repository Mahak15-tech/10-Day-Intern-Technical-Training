# Day 8 – SQL and Laravel

## 📌 Overview

This project focuses on SQL database management and Laravel API development.

The SQL practical includes creating a database, managing employee records, and performing CRUD operations.

## 🛠️ Technologies Used

- MySQL
- MySQL Workbench 8.0
- PHP
- Laravel
- SQL

## ✨ Features

- Create employee database
- Insert employee records
- Read employee data
- Update employee information
- Delete employee records
- Filter employees by department
- Calculate average and highest salary
- Perform aggregate SQL queries
