# Day 6 – EmployeeSphere

## Project Overview

EmployeeSphere is a modern employee management dashboard
built using React and TypeScript.

## Technologies Used

- React
- TypeScript
- Vite
- CSS
- LocalStorage

## Features

- View employee details
- Add new employees
- Edit employee information
- Delete employees
- Search employees
- Filter by department
- Calculate average salary
- Dark and light mode
- Persistent data using LocalStorage
- Responsive design

## How to Run

```bash
npm install
npm run dev

## Production Build

```bash
npm run build
```

- React components
