## Employee Management CLI

A command-line Employee Management System developed using Python.

### Features

1. Add Employee
2. Update Employee
3. Delete Employee
4. Search Employee
5. List Employees
6. Find Highest Salary
7. Filter Employees by Department
8. Exit

### Technologies Used

* Python

### How to Run

Open the `employee-management` folder in the terminal and run:

```bash
python employee_management.py
```
