# Day 9 - Angular Employee Dashboard

## Overview

An employee management dashboard developed using Angular, TypeScript, RxJS, and Laravel API.

## Technologies Used

- Angular
- TypeScript
- RxJS
- HTML and CSS
- Laravel REST API

## Features

- Fetch employee data from API
- Display employee records
- Angular service integration
- RxJS Observable usage
- API error handling

## API Integration

Backend API:

http://127.0.0.1:8000/api/employees

## Learning Outcomes

- Understanding Angular components
- Creating Angular services
- Using HttpClient
- Working with RxJS Observables
- Integrating frontend with REST API
