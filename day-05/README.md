## Practical Project
### Employee Dashboard

Features:
- Fetch employee data from a public API
- Display employee information
- Show employee name, email, company, and city
- Handle API errors
- Responsive dashboard layout

## Technologies Used
- HTML
- CSS
- JavaScript
- Fetch API
- JSONPlaceholder API

## How to Run

1. Open `index.html` in a web browser.
2. Click the **Load Employees** button.
3. View the employee information.
